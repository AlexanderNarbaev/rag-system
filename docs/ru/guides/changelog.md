# История изменений

Все значимые изменения проекта RAG System.

---

## v2.0.0 (2026-07-16)

### Конвейер RAG

- **Гибридный поиск** — плотный (BGE-M3) + разреженный (BM25) + ColBERT мульти-вектор с RRF-слиянием
- **Cross-Encoder-реранжирование** — MiniLM-L-6-v2 с двухэтапной фильтрацией и поддержкой дообучения
- **Граф знаний** — извлечение сущностей Neo4j (10 типов, 9 отношений), text-to-Cypher, глобальный поиск
- **Расширение запросов HyDE** — генерация гипотетических документов для повышения полноты
- **CRAG-оценщик** — оценка качества поиска с корректирующими петлями
- **NLI-обоснование** — детекция галлюцинаций через энтейнмент
- **Оценка уверенности** — эвристики + опциональная SLM-верификация, негативное отклонение
- **Оптимизатор токенов** — BPE-подсчёт, 4 стратегии сжатия, умное распределение бюджета

### Агентские инструменты

- **Tools SDK** — декоратор `@tool` с автоматической генерацией JSON Schema из аннотаций типов
- **Декларативные инструменты** — определения на YAML/JSON для HTTP и shell-команд
- **Авто-обнаружение OpenAPI** — автоматическое преобразование REST API в инструменты
- **Оркестратор инструментов** — параллельное выполнение с разрешением зависимостей
- **Безопасность** — песочница инструментов, проверка прав, аудит-логирование

### Эволюция моделей

- **LoRA/QLoRA-дообучение** — пайплайн для SLM, LLM и Reranker
- **EvalGate CI/CD** — контроль качества перед выкаткой моделей
- **Canary Controller** — постепенный rollout с разделением трафика
- **Adapter Manager** — горячая загрузка адаптеров без рестарта
- **MLflow Tracking** — трекинг экспериментов и реестр моделей

### MCP-сервер

- **STDIO-транспорт** — интеграция с IDE (OpenCode, Claude Desktop)
- **Streamable HTTP-транспорт** — интеграция удалённых агентов
- **Tools/Resources/Prompts** — полная поддержка протокола MCP

### Продакшен

- **Аутентификация** — JWT (пара access+refresh), Keycloak OIDC, LDAP/AD, API-ключи
- **RBAC** — 4 роли (admin, expert, user, read-only)
- **Мульти-KB** — изолированные Qdrant-коллекции на базу знаний, SQLite-метаданные
- **Rate limiting** — token bucket по IP и эндпоинту
- **Federated RAG** — fan-out между силосами с взвешенным RRF-слиянием
- **Наблюдаемость** — Prometheus-метрики, структурное логирование (text/JSON), Grafana-дашборды
- **K8s Helm-чарт** — HPA, пробы, секреты, network policies, 14 шаблонов
- **Air-gapped** — все модели предзагружены, полностью автономная работа

### ETL-конвейер

- **Экстракторы** — Confluence, Jira, GitLab, книги, документы, чаты, изображения, таблицы
- **Семантический чанкер** — адаптивное членение, контекстное членение, версионирование по хешу
- **WAL-инкремент** — checkpointing для возобновления
- **Стриминговый ETL** — Redis Streams, ingestion через webhook
- **Построитель графа** — spaCy NER, извлечение сущностей, загрузка в Neo4j

### Инфраструктура

- **Бэкапы** — Qdrant-снапшоты, Neo4j-дампы, Redis RDB, репликация MinIO
- **Ротация секретов** — автоматизированные скрипты ротации учётных данных
- **TLS** — автоматическое управление сертификатами
- **Миграции БД** — фреймворк миграций для эволюции схемы SQLite
- **Операционные скрипты** — health check, status, backup, restore, verification

### Документация

- **14 ADR** — архитектурные решения, охватывающие все ключевые узлы дизайна
- **44 руководства на EN** — полная документация по всем областям
- **30 руководств на RU** — полные русские переводы
- **C4-диаграммы** — 9 архитектурных диаграмм (L1, L2, L3, deployment, data flow, MCP, evolution)
- **OpenAPI-спецификация** — автоматическая v3.1-спека с 35+ эндпоинтами

### Безопасность

- Санитизация ввода (XSS, SQLi, инъекции, ограничения длины)
- Политика паролей (минимум 10 символов, заглавная, строчная, цифра, спецсимвол)
- Rate-limit на всех auth-эндпоинтах
- Маскирование секретов в логах
- Аудит действий auth и admin
- CORS-конфигурация и заголовки безопасности (HSTS, X-Frame-Options, CSP)
- Сканирование зависимостей (pip-audit, CodeQL)

### Спринт S4-2026 (2026-07-10 — 2026-07-16)

- **Волна 1** — строгий mypy (0 ошибок), фикс сбора тестов, разбор Dependabot, прод-багфиксы
- **Волна 2** — покрытие 80 %, расширение eval-датасета, аудит безопасности, полнота документации
- **Волна 3** — TLS-автоматизация, ротация секретов, миграции БД, бенчмарки K8s
- **Волна 4** — C4-диаграммы, экспорт OpenAPI, ADR-008 финализирован, аудит зрелости
- **Волна 5** — интеграционные тесты исправлены, покрытие проверено на 80 %

### Предыдущие спринты (S3-2026)

- Цикл самокритики, проводка CRAG-оценщика, кэш эмбеддингов
